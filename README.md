his project is a simple command-line Expense Tracker developed in Python. It allows users to enter multiple expense amounts and calculates the total expenses. The project helps beginners understand how to process numerical data using variables, loops, and mathematical operations.

Features

- Add multiple expenses
- Calculate the total amount spent
- Simple command-line interface
- Easy to understand and use

Concepts Used

- Variables
- User Input
- "while" Loop
- Mathematical Operations
- Accumulator ("total = total + expense")

Project Objective

The objective of this project is to learn how to collect, process, and calculate numerical data in Python. It is developed as Project 2 of the DecodeLabs Python Programming Internship.
